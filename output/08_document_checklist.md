# Document Checklist — Universal + Per-Program

**Date built:** 2026-05-04
**Purpose:** Track every document the applicant must prepare, organise, and (where relevant) ship by post.

## Universal documents (needed for almost every application)

| Document | Format | Where to obtain | Status (applicant to fill) |
|---|---|---|---|
| Bachelor's degree certificate (BTech IT) | PDF (scan) + 6 hard copies | Uttarakhand Tech University registrar | [ ] |
| Bachelor's official transcripts (semester-wise) | PDF (scan) + 6 hard copies, English (or with certified translation) | UTU registrar | [ ] |
| Class 12 / Higher Secondary certificate | PDF + 2 hard copies | School board | [ ] |
| Class 10 / Secondary certificate | PDF + 1 hard copy | School board | [ ] |
| APS certificate | PDF + 4 hard copies | Already in hand | [x] |
| IELTS TRF (Test Report Form) | PDF + 4 hard copies; arrange electronic dispatch via TRF Online | British Council / IDP | [ ] |
| Passport (bio-data page) | PDF scan | Already in hand | [ ] |
| Passport-size photo (35×45 mm) | digital + physical | Photo studio | [ ] |
| CV / résumé (1–2 pages, English) | PDF | Self-prepared | [ ] |
| Statement of Purpose (SOP / motivation letter) | PDF, ~1,000 words; per-program tailored | Self-drafted | [ ] |
| Letter(s) of Recommendation (2–3) | PDF on university letterhead, signed by referee | Faculty advisors / employer | [ ] |
| Bachelor thesis abstract | PDF (1–2 pages) | Self-prepared from BTech project | [ ] |
| List of Bachelor courses with grades + ECTS | PDF table; convert UTU credits to ECTS approximately | Self-prepared from transcripts | [ ] |
